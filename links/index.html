リンクDirect links into each activity

Put one of these on a worksheet and the app opens on that activity. The tab bar stays where it is: a student can still go anywhere, the same as always.

An app also reopens on whatever tab it was last used on, so a student who comes back mid-task comes back where they were.

Any link also takes a number instead of a name, counting from the left: ?tab=3 is the third tab.

This page is not linked from the hub. Keep the address or bookmark it.
